# Portfolio Fotograficzne

Portfolio fotograficzne stworzone w ramach projektu na studia. Strona prezentuje galerię zdjęć, informacje o mnie, ofertę oraz w pełni funkcjonalny formularz kontaktowy zintegrowany z serwisem FormSubmit.

## Technologie
Projekt został zbudowany przy użyciu czystych technologii webowych:
* **HTML5** – semantyczna struktura strony,
* **CSS3** – stylowie, responsywny layout oraz animacje,
* **JavaScript** – dynamiczne ładowanie elementów (header, menu, footer), podświetlanie aktywnej podstrony, filtrowanie zdjęć i lightbox,
* **FormSubmit** – backend-free obsługa wiadomości z formularza kontaktowego.
